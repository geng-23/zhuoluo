# 着落（zhuoluo）

一款让事事有着落的本地待办应用：任务、日历、四象限，数据全部保存在设备上，无需账号、无云端依赖。

> **⚡ Vibe Coding 作品** —— 本应用 **100% 由 AI 对话式驱动编写**，无一行人工手写源码。从最初的原型、功能迭代、缺陷修复到架构重构，全程通过自然语言向 AI 描述需求完成。

## 功能详解

### 快速添加（自然语言）

在任务页或日历页的输入框直接用中文描述任务，自动解析出计划时间、日期与重复规则：

```
明天下午3点交报告        → 明天 15:00
下3点开会                → 今天 15:00（"下"= 下午缩写）
晚上12点睡觉             → 今天 00:00（午夜）
每天晨跑                 → 全天重复（每天）
每周五例会               → 每周五重复
每两周健身               → 每 2 周重复（锚定创建日星期）
每两个月体检             → 每 2 个月重复
八月十日交报告           → 8 月 10 日
三天后交报告             → 相对日期 +3 天
下午三点到五点写方案      → 15:00–17:00（结束时间自动继承时段）
```

标题自动切除已识别的时间词（`明天下午3点交报告` → 标题 `交报告`），解析失败时文本原样保留为标题。

### 任务管理

- **智能视图**：全部 / 今天 / 最近 7 天 / 已完成 / 按清单 / 搜索结果
- **清单**：新建、重命名、改色、控制日历显隐、删除（可撤销）
- **排序**：手动拖拽排序（本地重排避免闪烁）
- **多选模式**：批量完成 / 恢复 / 删除 / 移动 / 全选，全部可撤销
- **完成/撤销**：滑动勾选 + 撤销条；重复任务按"今天实例"完成
- **回收站**：删除的任务（含整棵子树与提醒/完成记录）快照进回收站，可恢复 / 彻底删除 / 清空；保留期（默认 30 天）到期自动清理，偏好设置可调
- **搜索**：逐键实时过滤，清空自动退出

### 子任务

父任务下可挂多个子任务（仅在详情页展示）。子任务全部完成后父任务自动完成；恢复任一子任务时父任务联动恢复并重新排提醒。

### 日历

- **月视图**：横滑翻月，每格最多展示 2 个任务 + "N 个更多"徽标，长按任意日期快速添加
- **周视图**：多周横向滚动，日期头点击跳转日视图，拖拽任务边缘自动翻周
- **日视图**：横滑翻日
- **时间轴**：06:00–23:00，64px/小时，网格线，当前时间红线跨分钟平滑走秒
- **任务块**：全天/跨天任务置顶显示；重叠任务自动分栏（并查集分组，>2 合并 +N 徽标，跨午夜正确扩展）
- **拖动改期**：拖动任务块到新时间（10 分钟吸附、边缘自动翻页、跨天支持、重复任务系列确认、悬浮时间胶囊防手指遮挡）；置顶区任务（全天/跨天）长按拖到另一天——全天保持全天改日、跨天整体平移天数（保留起止时间与时长），拖进时间轴不生效
- **长按选时创建**：按住时间轴拖出选区创建任务，选区实时预览
- **实例操作**：完成 / 撤销 / 跳过本次 / 例外改期（写 RRULE 例外，可撤销）
- **月视图日预览**：点击任意日期弹出当日任务弹层

### 重复任务

- **规则**：每天 / 每周（指定星期）/ 每 N 天 / 每 N 周 / 每 N 月 / 每月 N 号 / 每年，支持 UNTIL 结束日期与 COUNT 次数
- **存储**：标准 RRULE 字符串，可被外部工具理解
- **实例级语义**：每个实例独立完成/撤销；跳过本次、例外改期均写例外记录，可撤销
- **锚点吸附**：创建或修改规则时，起始日期自动对齐到距其最近的规则命中日，保证"从日历消失"不再发生
- **任务页操作**：改期本次 / 改期全部（平移系列锚点）/ 删除本次 / 删除全部

### 提醒与通知

- 每任务可设多条提醒：相对提醒（提前 N 分钟）/ 自定义时刻 / 全天任务指定提醒时刻
- **精确闹钟**：Android zonedSchedule 精确到分钟，失败自动降级为 inexact
- **重复任务逐实例排期**：93 天滚动窗口全量重排，启动/恢复/时区变化时自动重建
- **通知 ID 隔离**：任务提醒（reminderId 大数槽位，含实例日维度，上限 12.8 万条提醒记录）、习惯提醒、测试通知三段独立区间，避免互相覆盖
- **点击深链**：通知点击直达对应任务详情（`t{id}`）或习惯页（`h{id}`）
- **锁屏可见**：通知渠道 + 通知级双重保证锁屏显示（MIUI 等厂商适配）

### 番茄专注

15 / 25 / 45 分钟三档，可关联任务，暂停/继续，完成后写入专注记录并计入统计。

### 习惯打卡

新建习惯（名称 + 每日提醒），按天打卡/取消（带撤销条），提醒到点弹通知；统计页有 90 天习惯热力图。

### 统计

- **周/月/年**范围切换，数据变更自动刷新
- **完成率卡片**：count-up 动画 + 每日条形图（完成/计划内嵌比例）
- **专注时长卡片**：区间内番茄记录汇总
- **年热力图**：GitHub 风格（闰年 366 天）

### 四象限

重要紧急 / 重要不紧急 / 紧急不重要 / 一般 四格看板，拖动任务归类，支持子任务。

## 中文自然语言解析

`lib/data/services/chinese_date_parser.dart` 是核心特色模块，支持数字与中文数字混写，按"重复规则 → 具体日期 → 时间 → 结束时间"顺序匹配，先命中先生效。

### 重复规则

| 输入                        | 结果                                                              |
| --------------------------- | ----------------------------------------------------------------- |
| `每天` / `每一天`           | `FREQ=DAILY`                                                      |
| `每周X`（一~日/天）         | `FREQ=WEEKLY;BYDAY=XX` + 首实例日期（本周未到取本周，已过取下周） |
| `每N天`（`每3天`/`每两天`） | `FREQ=DAILY;INTERVAL=N`                                           |
| `每N周`（`每2周`/`每两周`） | `FREQ=WEEKLY;INTERVAL=N;BYDAY=创建日星期`                         |
| `每N周X`（`每两周三`）      | `FREQ=WEEKLY;INTERVAL=N;BYDAY=X`                                  |
| `每N月`（`每两个月`）       | `FREQ=MONTHLY;INTERVAL=N`                                         |
| `每月N号`（`每月五号`）     | `FREQ=MONTHLY;BYMONTHDAY=N`                                       |

### 具体日期

| 输入                                    | 结果                                     |
| --------------------------------------- | ---------------------------------------- |
| `昨天`/`今天`/`明天`/`后天`/`大后天`    | ±1/0/+1/+2/+3 天                         |
| `N天后` / `N天之后`（`3天后`/`三天后`） | +N 天（必须显式"后"，裸 `3天` 不吞语义） |
| `下周X` / `本周X` / `这周X`             | 对应日期                                 |
| `周X` / `星期X` / `礼拜X`               | 最近一次（本周已过取下周）               |
| `M月D日`（`8月10日`/`八月十日`）        | 当年日期，月份已过自动进下一年           |
| `YYYY-MM-DD` / `YYYY/M/D`               | 指定日期                                 |
| `月底` / `下个月底` / `下个月月底`      | 当月 / 下月最后一天                      |
| `下个月N号`（`下个月五号`）             | 下月 N 日                                |
| `这个月N号` / `N号`（`五号`）           | 本月 N 日，已过自动进下月                |

### 时间

| 输入                             | 结果                        |
| -------------------------------- | --------------------------- |
| `3点` / `五点`                   | 03:00 / 05:00               |
| `3点半` / `五点半`               | 03:30 / 05:30               |
| `3点30分` / `七点二十分`         | 03:30 / 07:20               |
| `9:30`                           | 09:30                       |
| `下午3点` / `下3点` / `下午三点` | 15:00（"下"是"下午"的缩写） |
| `晚上8点` / `晚上八点`           | 20:00                       |
| `晚上12点` / `晚上十二点`        | **00:00**（午夜，不是正午） |
| `中午12点`                       | 12:00（正午）               |
| `凌晨12点` / `凌晨一点`          | 00:00 / 01:00               |

时段偏移规则：下午/晚上/傍晚 <12 点 → +12；晚上/傍晚 =12 点 → 0（午夜）；中午 <11 点 → +12；凌晨 =12 点 → 0。

### 结束时间（推断任务时长）

| 输入                              | 结果                                |
| --------------------------------- | ----------------------------------- |
| `下午3点到5点` / `下午三点到五点` | 15:00–17:00（结束自动继承起始时段） |
| `早上9点到下午2点`                | 09:00–14:00（显式结束时段优先）     |
| `下午3点到4点半`                  | 15:00–16:30                         |
| `晚上11点到1点`                   | 23:00–次日 01:00（跨午夜）          |
| `晚上12点到1点`                   | 00:00–01:00                         |
| `3点到5点`                        | 03:00–05:00                         |

### 数字能力

- 中文数字映射：`一~九`、`两`、`十`、`十一~十九`、`二十~九十九`（`二十二点` = 22:00，`三十五分` = 35 分）
- 非法组合自动忽略（如 `二三`、`13月40号` 通过回读校验拒绝，不会产生 `DateTime` 进位错误）

## 数据模型

SQLite（Drift），10 张表，schemaVersion = 6：

| 表                 | 关键字段                                                                                                   | 说明                                |
| ------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| `lists`            | name/color/sortOrder/showInCalendar/isDefault                                                              | 任务清单                            |
| `tasks`            | listId/parentId(子任务树)/title/quadrant/planStart/planEnd/dueTime/isAllDay/rrule/skippedDates/completedAt | 重复规则存 RRULE 字符串             |
| `reminders`        | taskId/remindMinutesBefore/isPersistent/remindAtMinutes                                                    | 每任务多条提醒                      |
| `task_completions` | taskId/instanceDate/completedAt，**唯一约束 (taskId, instanceDate)**                                       | 重复任务实例级完成                  |
| `task_exceptions`  | taskId/instanceDate/action(edit\|delete)/overrideScheduledDate                                             | RRULE 例外                          |
| `habits`           | name/frequency/reminderTime                                                                                | 习惯                                |
| `habit_records`    | habitId/date/completedAt，**唯一约束 (habitId, date)**                                                     | 习惯打卡（防双击并发重复）          |
| `pomodoro_records` | taskId(可空)/durationMinutes/startedAt/completedAt                                                         | 番茄专注                            |
| `settings`         | key/value                                                                                                  | KV 设置（主题/音效/自动备份时间等） |
| `trash_items`      | originalTaskId/title/listName/deletedAt/data                                                               | 回收站（已删除任务整棵树 JSON 快照）|

所有写操作原子事务 + 撤销快照；恢复备份为单事务原子替换（并清空回收站）。

## 技术架构

```
lib/
├── main.dart                入口：通知初始化→DB→默认清单→设置并行读取后 runApp；
│                            锚点修复/权限请求/全量重排/自动备份在首帧后异步执行
├── shell/home_shell.dart    四 Tab 壳（懒加载 IndexedStack + 通知深链）
├── core/                    基础设施（providers / services / theme / utils）
├── data/
│   ├── database/            schema + DAO + 迁移（database.g.dart 由 build_runner 生成）
│   └── services/            中文解析器 / 提醒调度器 / 通知服务 / 备份服务 / RRULE 展开器
└── features/
    ├── task/                任务列表 / 详情 / 计划时间与重复规则弹窗（独立文件）
    ├── calendar/            月/周/日视图（views 按时间轴/列/弹层拆分）
    ├── statistics/          统计
    └── profile/             我的 / 备份管理 / 番茄 / 习惯 / 四象限（独立文件）
```

**关键设计**

- **RRULE 展开器**（`rrule_expander.dart`）：解析 FREQ/INTERVAL/COUNT/UNTIL/BYDAY/BYMONTHDAY，提供窗口展开、命中判定、锚点吸附（`nearestHitOnOrNear`）
- **提醒调度器**（`reminder_scheduler.dart`）：增量排期 + 启动/恢复全量重排（93 天窗口）
- **平台条件编译**：备份文件系统操作按平台隔离（`backup_platform_io.dart`）
- **数据版本联动**：`dataVersionProvider` 全局版本号，任何写操作后 +1，日历/统计/四象限自动刷新

## 数据安全与备份

### 自动备份（每天首次打开）

- 启动后异步执行（不阻塞 UI），距上次备份 >24h 触发
- 写入**应用私有目录**（规避 Android 11+ 作用域存储对公共目录的限制）
- **保留最近 10 份**，更旧的自动清理（下载目录 + 私有目录统一按修改时间）
- 失败不打扰：仅"我的 → 备份管理"入口显示 ⚠ 角标 + 失败时间，点击进入后清除

### 备份文件

- 格式：JSON（9 张表全量 + 版本号），`version: 1`
- 文件名：`zhuoluo_backup_YYYYMMDD_HHMMSS_xxxx.json`（4 位随机后缀防同秒覆盖）
- 导出位置：Android 写入公共下载目录（`Download/着落/`），其余平台系统保存对话框

### 导入

- **合并导入（推荐）**：按标题去重并入当前数据，外键链（清单/父任务/任务/习惯）自动重映射，单事务原子，失败整体回滚
- **恢复并覆盖**：以备份为准全量替换；执行前自动安全备份当前数据，可随时回退
- 恢复后自动全量重排提醒、刷新主题/音效设置
